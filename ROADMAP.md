# Roadmap

The public roadmap for Modelplane is published as a GitHub project board:
[Modelplane Roadmap]. Issues on the roadmap have been triaged by the maintainers
and identified as valuable to the community, and are therefore a priority the
project expects to invest in.

The maintainers update the roadmap as needed, in response to demand, priority,
and available resources, and it can change at any time. Its order gives a sense
of overall priority and expected delivery, but it is an estimate, not a hard
commitment to a specific timeline.

## Influencing the roadmap

The roadmap is made of GitHub issues, so the way to shape it is through issues.
To support an existing request, add a :+1: reaction, and comment if your use
case differs from what's already on the issue.

To suggest new functionality for the roadmap, open a feature request and be sure
to follow the contributing guidance on [reporting issues] and [writing style].

If you want to work on a roadmap item yourself, [discuss the approach] on its
issue before you write code.
